# AI LifeHub

منصة تجريبية مصغّرة لتصوّر الفكرة الكبرى **AI LifeHub**: مساعد واحد متكامل يجمع
التقنية، التعليم، الصحة، والمهارات الاجتماعية في واجهة عربية بسيطة. تم بناء هذا
المستودع لتوضيح كيفية تنظيم الأكواد والتكامل مع نموذج Gemini لإنتاج تجربة متعددة
الوحدات.

## المتطلبات

- Python 3.11+
- مكتبة Google Generative AI (`google-generativeai`)
- مفتاح واجهة Gemini مخزن في المتغير البيئي `GOOGLE_API_KEY`

## التثبيت

1. إنشاء بيئة افتراضية وتفعيلها.
2. تثبيت الاعتماديات:
   ```bash
   pip install -r requirements.txt
   ```

## الاستخدام

يوفّر الملف `main.py` واجهة سطر أوامر لاستدعاء الوحدات المختلفة:

```bash
python main.py coach "عندي طاقة متوسطة، اجتماع صباحي، وأحتاج إنهاء تقرير قبل 5 مساءً"
```

سيتم طباعة النتيجة بصيغة Markdown مع اقتراحات عربية ودية.

### الوحدات المتاحة

| الكود | الوصف |
|-------|-------|
| `coach` | تنظيم اليوم الذكي |
| `cv` | تحسين السيرة الذاتية |
| `learning` | خارطة تطوير المهارات |
| `health` | مراجعة الصحة والعافية |
| `calm` | وضع التهدئة الذكي |
| `reply` | اقتراحات للردود |
| `post` | منشور اجتماعي |
| `tech` | تشخيص الأعطال التقنية |
| `explain` | شرح تعليمي |
| `quiz` | اختبار تفاعلي |

## بنية المشروع

```
ai_lifehub/
  core/          # إعدادات Gemini وملف العميل العام.
  modules/       # كل وحدة حياة يومية مستقلة بمنطقها الخاص.
main.py          # واجهة سطر الأوامر للتجربة.
```

كل وحدة تتواصل مع Gemini باستخدام تعليمات نظام محددة لضبط نبرة الحديث ومجال الخبرة،
ويمكن توسيعها لاحقًا لإضافة تحليل صوت أو صورة حسب الحاجة.
